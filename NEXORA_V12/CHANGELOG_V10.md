# NEXORA V10

Major experience upgrade focused on AI + human interaction, not just learning/software.

## New
- NEXORA animated AI companion that follows the user across the app.
- Companion states: idle, happy, error, pulse/float animations.
- AI modes: Companion, Coach, Creator, Planner, Tutor.
- Voice input using browser SpeechRecognition when supported.
- AI voice playback using browser SpeechSynthesis when supported.
- Command Center for natural-language goals and quick actions.
- Connect hub for people search, social presence/status and conversation starters.
- Creative Studio for polishing, social copy, concise writing and idea generation.
- Projects/workspaces stored locally for the current browser profile.
- Focus Mode with functional 25-minute timer.
- Stronger AI presentation, thinking animation, response speech and quick prompts.
- Mobile-friendly companion and responsive AI controls.
- Preview-mode support for new features so the app remains usable without the backend.

## Reliability
- Preserved existing NEXORA social, messaging, marketplace, opportunities, events, wallet, profile, safety and admin functionality.
- Avoided breaking the existing Socket.IO connection function by using a distinct Connect page handler.
- Added demo-mode support for member search.
- Updated version to 10.0.0.
