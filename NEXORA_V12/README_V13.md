# NEXORA V13

NEXORA V13 keeps the V12 AI rebuild and animated thinking experience while adding deployment and mobile-build infrastructure.

### Included
- Node.js + Express backend
- Socket.IO realtime layer
- Server-side AI adapter with local fallback
- Animated AI thinking state
- M-Pesa Daraja integration hooks
- Configurable data/upload directories
- Render deployment Blueprint
- Capacitor Android configuration
- GitHub Actions Android APK build

Read `PRODUCTION_DEPLOY.md` before using real users, money or production credentials.
