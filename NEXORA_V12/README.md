# NEXORA V10

NEXORA is a social-first AI-powered platform for connecting, communicating, creating, discovering opportunities, communities, marketplace activity and everyday assistance. V10 adds an animated AI companion, Command Center, Connect hub, Creative Studio, Projects and Focus Mode while retaining the existing platform features.

## Run

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm start`.
4. Open the local address shown by the server.

For a browser-only preview, open `public/index.html` and choose Preview NEXORA. Some browser security policies may limit direct-file behavior; the Node server is recommended.

See `CHANGELOG_V10.md` and `QA_REPORT_V10.md`.
