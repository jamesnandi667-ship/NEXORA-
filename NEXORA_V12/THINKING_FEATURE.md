# NEXORA AI — Natural Thinking Moment

NEXORA now pauses for a natural 2.2–3.4 second thinking moment before revealing an AI answer. During the pause, the chat shows an animated NEXORA orb/sticker, expanding rings, and animated dots with “Thinking… / Let me think about that”.

The AI request runs in parallel with the visual delay, so real API responses are never unnecessarily delayed beyond the minimum thinking moment. Errors still replace the thinking state with a retryable error message.
