# NEXORA v7 Feature Map

## Social
- Feed with text, images, videos and documents
- Create, edit and delete own posts
- Like, comment, share and save
- Saved posts collection
- People search and follow/unfollow
- Block members and hide blocked content
- Notifications for follows, likes, comments, applications and messages

## Communication
- Community group chat through Socket.IO
- One-to-one direct messaging
- Typing indicator
- Online presence signaling
- One-to-one WebRTC video-call signaling

## Work & business
- Jobs, freelance, internships, services and business opportunities
- Opportunity applications with messages
- Application tracking page
- Marketplace products, services and digital listings
- Listing images
- Contact seller through direct messaging
- Share opportunity/listing text
- Events with capacity and RSVP/cancel RSVP

## Stories & media
- Real story upload for image/video
- 24-hour story expiry
- Story captions
- Post media/document uploads

## Learning
- Course catalog
- Course progress tracking in 25% increments
- Completion state

## Identity, privacy & monetization
- JWT authentication
- bcrypt password hashing
- Profile editing and profile photo upload
- Premium KSh 100/month
- M-Pesa Daraja STK Push + callback reconciliation
- Premium payment history
- Notification and private-profile settings
- Personal data export
- Report and block tools
- Support ticket submission

## UX / reliability
- Supplied NEXORA artwork is the primary app logo/favicon/PWA icon
- Relative asset paths
- Mobile responsive navigation
- Back navigation
- Light/dark theme
- PWA manifest/service worker
- Local demo mode for offline/preview testing
- Backend schema self-healing for missing arrays
- Upload type and size validation
- API error handling
- Empty/loading states
